# 🛒 Amazon Product Analysis Dashboard

A modern, interactive data analytics dashboard built with **Streamlit** to explore and visualize Amazon product data. This project performs comprehensive **Exploratory Data Analysis (EDA)** and presents meaningful business insights through an intuitive dashboard.

---

## 📌 Project Overview

The goal of this project is to analyze Amazon product data to uncover patterns in pricing, customer ratings, product popularity, and marketplace trends. The dashboard enables users to interactively explore the dataset using filters and visualizations.

---

## 🚀 Features

- 📊 Interactive KPI Cards
- 🔍 Dynamic Sidebar Filters
- 💰 Product Price Distribution
- ⭐ Product Star Rating Analysis
- 📈 Product Price vs Original Price
- 📉 Product Price vs Number of Ratings
- 🔥 Correlation Heatmap
- 🏆 Top Rated Products
- 🛍️ Most Reviewed Products
- 📋 Interactive Product Table
- 💡 Key Business Insights

## 📦 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/amazon-product-analysis-dashboard.git
```

Move into the project directory

```bash
cd amazon-product-analysis-dashboard
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```

## 📊 Key Insights

- Most products have customer ratings above 4.0 stars.
- Product price generally increases with original price.
- Product ratings show only a moderate relationship with the number of ratings.
- Most numerical variables exhibit weak correlations.
- Several products are offered at discounted prices compared to their original listings.
